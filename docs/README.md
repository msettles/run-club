# Run Club documentation

Public project website: [Run Club](https://msettles.github.io/run-club/). The website publishes selected guides from this directory; the full technical record stays here.

Current app release: **1.6.5**, deployed November 15, 2026. These guides describe the Woodland Woodchuckers app. Scheduled run cards are the source for each event's time, venue and routes.

## Using the app

| Start here | What you will find |
| --- | --- |
| [Runner guide](help/runner-guide.md) | Join, sign in, RSVP, check in, view My Runs, claim history, use routes and install the app. |
| [Organizer guide](help/organizer-guide.md) | Schedule runs, manage routes, run the table, assist check-ins and hand out gear. |
| [Troubleshooting and FAQ](help/troubleshooting.md) | Sign-in, missing attendance, history, GPS, notifications and app updates. |
| [Roles and permissions](roles-and-permissions.md) | What guests, runners, organizers and admins can see and change. |
