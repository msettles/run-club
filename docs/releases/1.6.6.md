# Release 1.6.6

November 17, 2026.

Installed app icons now give the woodchuck mark more room within circular phone masks and shift it slightly left for visual balance. The approved artwork remains unchanged. Standard PWA, Android maskable, and Apple touch icons use the same sizing and placement; `scripts/generate-install-icons.py` regenerates them with Pillow.

The complete mark fits within an 86% circle. Some outer decorative strokes extend beyond Android’s conservative 80% safe zone, so other launcher shapes still need device verification. Existing shortcuts may need to be removed and added again after deployment to refresh the cached icon.

Deploy hosting and Firestore rules together from this committed release. No function or club-data changes are required.
