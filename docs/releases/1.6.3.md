# Release 1.6.3

November 14, 2026. Git tag: `1.6.3`. Owner-authorized commit, push and deployment.

## Resulting behavior

- Staff Run Night/Table Mode shows live attendance, actual route/activity/pet headcounts, private code word, gear queue and fulfillment.
- Assisted check-in searches registered runners, confirms route/activity/loops/pets, and uses a staff-authorized server transaction inside the normal window. Attendance, mileage, RSVP, rewards and the private staff audit are atomic. Retries do not double-count; maintenance/imports pause the workflow, and fulfilled gear is preserved.
- Private My Runs combines dated app/claimed attendance without duplicates, separates additive undated credits, renders pages of 25 and links recorded runs/routes on demand.
- Profile-based historical claiming provides available-name search, confirmation, existing transactional reconciliation and interrupted-claim recovery.
- Social publishing code/preview/tests are included, with one route-map photo per attached route in a single Facebook/Instagram post. Account configuration and Meta activation remain pending. Meta functions are not exported from the active function entry point, so this release does not inspect/provision their unconfigured secret or send social posts.
- Documentation closes resolved launch items and records these features and their limits. Existing approved artwork and mobile fixes from 1.6.1/1.6.2 remain intact.

250 unit tests, 54 emulator integration tests, 78 rules/seed checks and the full 46-case Chromium/mobile WebKit suite passed for the feature source.
