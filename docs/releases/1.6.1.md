# Release 1.6.1

November 14, 2026. Git tag: `1.6.1`.

This patch improves iPhone layouts throughout the club app and removes the redundant Copy link button. Share run retains the native share sheet and clipboard/manual-link fallbacks.

## Changes

- Run-card and route actions wrap inside their cards; Date and Start Time stack on small screens.
- Native form controls shrink within their containers, and tall dialogs keep their top controls reachable.
- The home banner fits narrow screens, and the footer reserves the iPhone bottom safe area.
- Admin navigation uses two columns on phones; event dates, reward details and badge-preview labels wrap with adequate spacing.
- Brand/check-in headers retain visible close controls. Profile setup fits long email addresses and stacks its fields on phones.
- Map-style controls wrap clear of zoom buttons; direction-mode buttons move below the heading when needed.

## Verification

Reviewed the main pages, admin sections and related dialogs in mobile WebKit at narrow portrait and landscape sizes, including populated check-in/roster states, historical-name selection and expanded import panels. Physical iPhone keyboard and installed-PWA behavior were not newly verified.

Validated the isolated release with Node 24: 221 unit tests, 30 Chromium/mobile WebKit browser checks, the Firestore security-rule/seed suite, browser type checking, production build and lazy-bundle checks passed. ESLint completed with zero errors and 46 existing warnings. Build again after committing so the displayed version/commit matches the deployed source.

## Deployment scope

Deploy hosting and the matching Firestore rules to the existing `woodland-woodchuckers` project. Rules and calendar-function source are unchanged. This patch does not deploy the separate unfinished social-publishing implementation or include local review artifacts and private working files. No club data reset, import, deletion, account change, route change or launch announcement is part of this release.
