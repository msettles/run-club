# Release 1.6.2

November 14, 2026. Git tag: `1.6.2`.

Updates the Logos & Brand page with the existing approved artwork library, accurate download details and an iPhone-friendly layout.

## Changes

- Preview and download all five 2026 Run Crew variants: transparent, black on cream, cream with teal border, black on teal and white on teal.
- Download the current woodchuck app mark on teal or with transparency, plus the heritage bottle-cap logo.
- Show actual pixel dimensions, file formats and background types, with practical artwork usage notes.
- Present the configured club colors as keyboard-accessible buttons that copy hex codes and explain clipboard failures.
- Describe Oswald, Outfit and Plus Jakarta Sans as app fonts, independently of the lettering embedded in the artwork.
- Use a compact header, scrollable content and reachable close controls on phones and landscape screens.
