## Resulting behavior

- Organizers/admins get Run Night/Table Mode: live attendance, actual route/activity/pet headcounts, private code word, gear queue and fulfillment.
- Assisted check-in searches registered runners, confirms route/activity/loops/pets and uses a staff-authorized server transaction inside the normal window. It writes attendance, mileage, RSVP, rewards and a private audit atomically, refuses maintenance/imports and preserves fulfilled gear. A retry or concurrent request cannot double-count attendance.
- Signed-in runners get private My Runs with display pagination, historical deduplication, additive undated credits and recorded run/route links.
- Profile historical claiming uses existing reservations/reconciliation and recovery, with an honest upper-bound preview and exact totals after confirmation.
- Social-post preview/publishing source and tests are included. Real Meta publishing remains inactive until the club accounts and server secret are configured; this deployment does not publish posts or provision the Meta sender functions.
- Documentation closes resolved launch follow-ups and distinguishes implemented features, pending Meta setup and absent push automation.
