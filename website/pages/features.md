# Built around run night

A shared schedule, a quick check-in and useful tools for the table team. These features are implemented in the current Woodland Woodchuckers application.

## For runners

- **Find the next event.** View published runs, venue, route choices and pace groups; RSVP, share a public link or add the run to your calendar.
- **Check in once.** Enter the code word, choose a saved route and allowed loops, then record running/walking and pet participation. The normal window opens two hours before start and ends at midnight Pacific.
- **See your history.** My Runs combines app attendance and claimed historical records, with shared dated runs counted once and undated credits shown separately.
- **Recognize progress.** View standings, badges, streaks and milestone gear. Update your profile and shirt size yourself.
- **Take the route with you.** Explore maps, directions, elevation and available Garmin/Strava/RunGo links, or download a GPX file.
- **Install the app.** Use a Home Screen shortcut and enable notifications on supported devices. Changes still need a confirmed online save.

[Read the runner guide](../../docs/help/runner-guide.md)

## For organizers

- Create and edit runs, attach routes and set the private code word.
- Open **Run Night / Table Mode** for live attendance and route/activity/pet headcounts.
- Assist registered runners within the normal check-in window, without duplicate attendance.
- Look up attendees and their provided emergency contacts, and hand out pending milestone gear.
- Manage routes with protections for routes already used by a run.

Staff controls appear in a separate **Organizer tools** group. Guests and ordinary members do not receive them.

[Read the organizer guide](../../docs/help/organizer-guide.md)

## For admins

Manage member roles, historical-name claims and imports, attendance corrections, badges, special events, milestone definitions and the club-wide gear queue. Post in-app announcements, inspect notification registrations and pause club changes for planned maintenance.

Only admins can delete users or check-ins. Club records are retained indefinitely unless an authorized person explicitly deletes them, subject to integrity safeguards.

[Review roles and permissions](../../docs/roles-and-permissions.md)
