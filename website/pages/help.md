## A few useful distinctions

- **RSVP is a plan; check-in is attendance.** Wait for a successful save before counting a run as recorded.
- **Announcements and phone pushes are separate.** The bell shows in-app announcements; there is no automatic run reminder yet.
- **Staff assistance uses the normal window.** There is no organizer or admin check-in-window bypass.
- **The live Woodland app contains real club data.** A separate fictional demonstration is planned.

## More detail

[Roles and permissions](../../docs/roles-and-permissions.md) explain who can do what. Maintainers can find import formats, operational policies and historical release records in the [repository documentation index](../../docs/README.md).

For an account or attendance problem, ask your club organizer or admin. For a reproducible software problem, [open a GitHub issue](https://github.com/msettles/run-club/issues). Keep registration emails, sign-in links, code words and emergency contact details out of public issues.
